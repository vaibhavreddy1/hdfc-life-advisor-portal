
# HDFC Life Advisor Portal

A Next.js 14 advisor portal built using the Pages Router.

## Features

- Policy catalogue using SSG and ISR
- Dynamic policy detail pages
- Catch-all policy category filtering
- Optional catch-all documentation route
- Claims desk using SSR
- Claim submission form using Formik and Yup
- NextAuth credentials authentication
- Optional Google authentication
- Protected Advisor Desk
- Middleware protection for `/desk`
- On-demand ISR revalidation API
